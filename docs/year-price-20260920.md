# 국가 · 모델 · 제조연식 가격 비교

- 국가·모델 페이지의 상단 비교 영역. 전체 국제 건설기계 매물 중 원화 1천만원 이상, 국가와 정규화 모델이 확인된 매물 수로 상위 30개 모델을 정한다. 동률은 모델명 순. 아래 기존 시장 탐색 필터와 독립적이다.
- 제조연식이 1950~현재 연도인 매물만 그래프에 쓴다. 등록일·수집일로 연식을 보충하지 않는다. 미상·비정상 연식 제외 건수를 표시한다.
- 모델별 연식 확인 매물 수 상위 8개 국가를 후보로 제공하고 최대 5개를 동시에 비교한다. 생략 국가/표본 범위를 표시한다.
- 가로축 제조연식, 세로축 원화 판매 희망가격. 국가별 색, 중앙값 점, 중간 50% 가격 범위 막대. 같은 국가의 연속 연식이 모두 최소 표본 기준을 만족할 때만 연결한다.
- 최소 표본 3/5/10건. 부족 표본은 빈 점과 참고값으로 구분하고 국가 가격차 계산에는 포함하지 않는다. 선택 연식에서 적격 국가가 2개 이상일 때만 최저 국가 중앙값 대비 차이를 계산한다.
- 가격은 게시 희망가격이며 실거래가·수요·과거 가격 추이·감가율이 아니다. 세부사양, 가동시간, 상태, 세금, 운송비의 영향은 남아 있다.
- 순위와 연식 집계는 기존 DB 조회 캐시를 공유한다. 추가 원격 크롤링이나 모델 사전 변경은 없다.
- 회귀 테스트: 정확한 3변수 조합, 중앙값/IQR, 상위30 안정성, 모델명 구분, 연식 미상·미래·비정상 제외, 소수 표본, 국가 상한.
