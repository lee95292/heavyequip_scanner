# 캐터필러 구형 모델 확장 (2026-10-18)

- 카탈로그: 878 → 1,780개 레코드. 캐터필러 328 → 1,230개.
- 추가: 14개 장비군 902개 모델 항목, 주요 사실 제원 8,241개.
- 도저 64개 추가: D6H, D9N, D8N, D7H, D10N, D11N, D6E, D6G 등.
- 출처: Caterpillar Performance Handbook Edition 50, June 2022, Former Models. 공식 딜러 Wheeler Cat 공개본. 문서의 구형 목록은 PHB49 이후 갱신 중단이라고 명시되어 있음.
- 모델 기본 이름으로 묶고 각 수치에 원문 구성, 일련번호 접두사, 제작 연도 표기, PDF 페이지, 원문 셀 및 병기 단위 보존.
- 숫자로 시작하는 CAT 모델은 `CAT265`, `CAT966F`로 표시. 원래 이름/ID는 유지. 원래 이름, CAT 접두사, 띄어쓴 CAT 접두사로 검색 가능.
- 서로 다른 중량 기준은 통합하지 않음. 원문 병기 단위 충돌 61개 값은 상세에 남기고 수치 필터/유사도에서 제외.
- 유사 도저 비교에서 휠식/궤도식 구분.

## 재현 및 범위

`collect-cat-former-models.py <PHB50.pdf> <v4/index.json> <additions.json>` (pdfplumber 필요).
추가 JSON 및 audit JSON은 Git에 포함. 원본 PDF와 완성 스냅샷은 Git 외부 보관. 출처 SHA-256과 모델별 URL/페이지로 검증 가능.

본 추가는 지정한 구형 장의 지원 표 형식에 대한 수집이며 전 세계·역대 전수 수집 선언이 아니다. 기존 동일 이름·장비군은 중복 추가하지 않음. 농업용, 일부 특수 광산·드릴·임업 및 혼합 형식 표는 자동 수치 해석에서 제외. 안전하게 해석하지 못한 6개 행은 audit의 held에 보존. 일부 모델은 다른 정상 행으로 이미 수록되어 있음. 자료 범위 밖의 모델은 이름 규칙으로 생성하지 않음.

## 검증

Python importer 및 원문 회귀 테스트, Node API/검색/유사도 테스트, Vite 프로덕션 빌드. 로컬 D9N 상세·유사도, CAT265 별칭 검색 확인. 배포는 `deploy-specifications-legacy.py`로 기존 v4와 설정 파일을 보존하고 검증 후 v6 활성화; 실패 시 이전 데이터/정적 파일로 롤백.
